访问限制

按顺序检查：IP 白名单 → IP 黑名单（命中返回 403）→ UA 白名单 → CF-IPCountry 国家（均未命中返回 403）→ 限速（超出返回 503）。
CF-IPCountry 仅在连接来自可信代理（Cloudflare / 自有服务器 / 内网）时才采信，防止伪造。

放行国家

ISO 两位国家码，逗号、空格或换行分隔。

UA 白名单

每行一个关键字，User-Agent 包含即放行（不区分大小写）。

IP 白名单

每行一个 IP 或 CIDR，# 后为注释。默认含 bwh8 / dmit01 / dmit02 / hehk03 / v99 及内网段。

IP 黑名单

每行一个 IP 或 CIDR（如 1.2.3.0/24），# 后为注释。命中返回 403，优先于 UA 白名单和国家放行；IP 白名单中的地址不受黑名单影响；仅在启用访问限制时生效。
可在「访问分析」页按 /24 网段一键加入。

限速（滚动窗口）

在上面的访问规则之后执行（只统计已放行的请求），即使未启用访问限制也生效；超出上限返回 503 并带 Retry-After。计数器在进程内存中，多实例部署时各实例分别计数。
